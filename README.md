# Vice City Poster Maker

Free, GTA 6-inspired poster maker: upload a selfie, get a nickname, wanted level and stats, download a neon poster.
Runs fully in the browser (canvas). No uploads, no server, no API costs.

Live: https://ahmadellahib.dev/vice-city-poster/ (English) · https://ahmadellahib.dev/vice-city-poster/ar/ (Arabic)

Fan-made. Not affiliated with Rockstar Games or Take-Two Interactive. All artwork is original.
